# 变形框收分缩放 (su-taper-scale)

> SketchUp 插件：像 FredoScale 的「自由比例缩放」那样，用一个**变形框**对选中对象做**拉伸缩放**和**收分（锥化）**，
> 支持**锁定方向轴**、**拖动吸附到角点/中心/端点**、**面心拉伸保持造型**、以及**精确增量输入**（`100` = 延长 100mm，`-100` = 缩短 100mm）。
>
> 纯 SketchUp Ruby API 实现，**不依赖 Fredo6 的任何库**，源码全部开源可改；**不占用任何键盘快捷键**。

## 功能

- **点命令 → 再选对象**：点工具栏/菜单命令后不需要先选东西，直接在模型里点击要变形的对象；鼠标悬停会高亮（青色虚线框），`Shift` / `Ctrl` / `Option` 点击可加选，点空白处重新选择。也兼容「先选中再点命令」。
- **变形框**：自动生成有向包围盒；只选一个组/组件时对齐**对象自身坐标轴**（旋转过的柱子也能沿自身轴线收分）。
- **拉伸缩放**：8 个角点手柄 + 6 个面心手柄，对侧固定，仿射变换直接作用于实体的放置矩阵。
  - 面心拉伸有两种行为，右键菜单二选一：
    - **保持造型（只拉伸中段）** ← 默认：自动找一条不切断特征的切分面，固定端完全不动、另一侧连同上面的**凹槽/倒角/角度整体平移**，只把中段拉长（同 AutoCAD STRETCH）；
    - **整体缩放（旧行为）**：整根等比缩放。
- **收分（锥化）**：固定端截面不变、另一端绕轴线按比例收缩、中间截面线性过渡；逐顶点变形，**材质、贴图、柔化平滑、组结构全部保留**。
- **拖动吸附**（可关）：拾取鼠标附近几何的特征点 —— 组/组件的**包围盒 8 角点 + 6 面心 + 中心**，散几何的**端点 / 中点 / 圆心**；命中时显示品红标记与「拾取：角点/中心/…」。
- **锁定方向轴**：点一下手柄即锁定该轴，之后鼠标怎么动都只沿这条轴缩放，再点一下应用。
- **精确输入**：右键「精确输入…」输入增量，正数延长、负数缩短；角点手柄可分别输入 X / Y / Z。
- **模式切换按钮**：视图左上角的半透明橙色圆角按钮，点一下就切换 拉伸缩放 / 收分（收分模式变形框变紫）。
- 操作全程在**一个撤销步骤**内，`Ctrl+Z` 一次整体回退。

## 安装

### 方式 A：安装包（推荐）

1. 下载 `ban_taper_scale.rbz`（见 Releases，或按下方「从源码构建」自己生成）；
2. SketchUp 菜单 `窗口 → Extension Manager（扩展程序管理器）`；
3. 点 `Install Extension`，选择 `ban_taper_scale.rbz`，未签名提示选择继续安装；
4. 重启 SketchUp。

安装后出现：工具栏「变形框收分缩放」+ 菜单 `扩展程序 → 变形框收分缩放`。命令**始终可以点**。

### 方式 B：手动复制源码

```bash
git clone https://github.com/biubiup0/su-taper-scale.git
```

把仓库里的 `ban_taper_scale.rb` 和 `ban_taper_scale/` 目录复制到：

```
~/Library/Application Support/SketchUp 2026/SketchUp/Plugins/      # macOS
%AppData%\SketchUp\SketchUp 2026\SketchUp\Plugins\                # Windows
```

### 从源码构建 .rbz

```bash
ruby tools/build.rb        # 生成图标并打包为 ban_taper_scale.rbz
```

## 使用

### 基本流程

1. **点工具栏按钮 / 菜单「变形框收分缩放」**（不需要先选中任何东西）；
2. 鼠标移到对象上会看到**青色虚线框**提示将要选中它；**点击**即选中并生成变形框；
3. `Shift` 或 `Ctrl`（Win）/ `Option`（Mac）点击可**加选**；
4. 拖手柄变形；**点空白处**可清空选择、重新挑对象；`Esc` 退出工具。

### 两种变形操作方式

1. **点一下 → 移动 → 再点一下（推荐）**：点手柄即**锁定方向轴**（绿色虚线标出），移动鼠标沿轴缩放，再点一下应用；`Esc` 取消。
2. **按住拖动**：按住手柄拖到目标位置松手，立即应用。

### 拖动吸附

拖动时会在鼠标附近寻找可吸附的特征点（屏幕 12 像素内），命中就画**品红方块**并在左上角显示类型：

| 鼠标附近的对象 | 可吸附的点 |
| --- | --- |
| 组 / 组件 | 包围盒 8 个角点、6 个面心、几何中心 |
| 散几何（面 / 线） | 端点、中点、圆弧圆心、面心 |

不需要时可在右键菜单里关掉：**「拖动时吸附到几何（端点/中点/圆心）」**。

### 切换模式

- 点视图**左上角的橙色圆角按钮**（上面写「切换模式」）—— 不依赖任何键盘快捷键，Mac / Windows 通用；
- 或右键菜单：「拉伸缩放模式」/「收分模式」；
- 切换后左上角会弹出大字提示，收分模式的变形框整体变**紫色**，手柄数也随之变化（拉伸 14 个，收分 6 个）。

### 右键菜单一览

| 菜单项 | 作用 |
| --- | --- |
| 精确输入… | 输入增量（正数延长 / 负数缩短），角点可分别输入 X/Y/Z |
| 应用 / 取消当前锁定 | 结束或取消当前变形 |
| 拉伸缩放模式 / 收分模式 | 切换模式（同按钮）|
| 变形框对齐对象坐标 | 用对象自身轴向建框 / 改用世界坐标轴 |
| 面心拉伸：保持造型 / 整体缩放 | 面心拉伸的两种行为 |
| 拖动时吸附到几何 | 吸附开关 |
| 收分时炸开圆/弧曲线 | 曲线处理开关 |

### 精确缩放

**方式一：右键「精确输入…」（推荐）** —— 先点一下手柄锁定方向轴，再右键：

| 输入 | 含义 |
| --- | --- |
| `100` | 沿锁定轴**延长 100**（按模型单位；模型是毫米就是 100mm）|
| `-100` | 沿锁定轴**缩短 100** |
| `100mm`、`3"` | 带单位时按该单位延长 / 缩短 |

**方式二：拖动时直接敲数字（VCB）**

| 输入 | 含义 |
| --- | --- |
| `100` / `-100` | 增量：延长 / 缩短 100（模型单位）|
| `100mm` | 带单位的增量 |
| `1.5x` / `*1.5` | 比例：放大到 1.5 倍 |
| `1200mm,800mm,1500mm` | 三个轴各自的增量（正负均可）|

**收分模式**的数值输入仍是「比例 / 端面尺寸」：`0.6` = 收分端缩到 0.6；`0.6,0.8` = 两个方向分别收缩；`600mm,900mm` = 收分端截面精确为 600×900mm。

### 「收分」的数学

```
t = 沿收分轴的归一化位置（固定端 = 0，收分端 = 1）
截面缩放 s(t) = 1 + (factor - 1) · t
结果点 = 轴线上的对应点 + s(t) · (原点到轴线的垂距)
```

## 注意事项

1. **收分会把组件「独立化」**：如果选中的组件被多处引用，插件会自动 `make_unique`，只影响你选中的那个实例。
2. **收分默认会炸开圆/弧曲线**（避免顶点移动后 SketchUp 重新拟合曲线导致形状异常），可在右键菜单关闭。
3. 收分是逐顶点变形：顶点特别多（约 8 万以上）时实时预览可能略卡，状态栏会提示。
4. 收分不改变变形框本身，可反复微调；拉伸缩放会同步更新变形框。
5. 「保持造型」的中段切分面是自动选的（相邻顶点之间最大的空档）；如果某个特征正好跨在切分面上，那条特征会被拉伸。
6. **不占用任何键盘快捷键**（早期版本的 Tab / M 已移除）。
7. 需要 SketchUp 2019 或更高版本（用到 `make_unique`、`transform_by_vectors` 等 API）。

## 自检（在真机验证）

安装并重启后，打开 `窗口 → Ruby 控制台`：

```ruby
load '<本仓库路径>/selftest.rb'
```

它会在模型里临时建一根柱子、跑一遍收分、校验顶点结果，然后**先回滚、再兜底删除测试几何**，不会留下任何东西。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `ban_taper_scale.rb` | 扩展加载入口（注册 SketchupExtension）|
| `ban_taper_scale/main.rb` | 菜单 / 工具栏 / 命令 |
| `ban_taper_scale/tool.rb` | 交互工具：点选对象、手柄、锁定方向轴、吸附、中段拉伸、按钮、精确输入、绘制、撤销 |
| `ban_taper_scale/vertex_set.rb` | 顶点收集与逐顶点变形（`transform_by_vectors`）|
| `ban_taper_scale/deform_box.rb` | 有向变形框（支持任意坐标系）|
| `ban_taper_scale/deform_math.rb` | 拉伸与收分的数学定义 |
| `ban_taper_scale/vec_math.rb` | 向量运算（按分量计算，避开 `Vector3d` 的运算符坑）|
| `ban_taper_scale/settings.rb` | 偏好设置（吸附、保持造型等）|
| `selftest.rb` | 真机自检脚本（不留下测试几何）|
| `tools/build.rb` | 生成图标并打包 .rbz |
