# 变形框收分缩放 (su-taper-scale)

> SketchUp 插件：像 FredoScale 的「自由比例缩放」那样，用一个**变形框**对选中对象做**拉伸缩放**和**收分（锥化）**，
> 支持**锁定方向轴**、**拖动吸附到角点/中心/端点**、**面心拉伸保持造型（拉伸区还能自己指定 1~2 段）**、以及**精确增量输入**（`100` = 延长 100mm，`-100` = 缩短 100mm）。
>
> 纯 SketchUp Ruby API 实现，**不依赖 Fredo6 的任何库**，源码全部开源可改；**不占用任何键盘快捷键**。

## 功能

- **点命令 → 再选对象**：点工具栏/菜单命令后不需要先选东西，直接在模型里点击要变形的对象；鼠标悬停会高亮（青色虚线框），`Shift` / `Ctrl` / `Option` 点击可加选，点空白处重新选择。也兼容「先选中再点命令」。
- **变形框**：自动生成有向包围盒；只选一个组/组件时对齐**对象自身坐标轴**（旋转过的柱子也能沿自身轴线收分）。
- **拉伸缩放**：8 个角点手柄 + 6 个面心手柄，对侧固定，仿射变换直接作用于实体的放置矩阵。
  - 面心拉伸有两种行为，右键菜单二选一：
    - **保持造型（只拉伸中段）** ← 默认：只把物体中部的一小段拉长 / 压短，两端造型（斜角、凹槽、锥面）**整体平移，形状一点不变**（同 AutoCAD STRETCH）；
    - **整体缩放（旧行为）**：整根等比缩放。
  - **拉伸区可以自己指定**：右键「拉伸区域设置…」，填 1 个或 2 个**互不相连**的区间（如 `30-40` 或 `30-40,60-70`）。
    伸长量按区间宽度分配（两段各占一半），区间以外全部刚性平移，**总长变化正好等于你拖动的量**
    （拖 100mm 就延长 100mm，和「精确输入」语义一致）。设置后画面上画出**半透明橙色拉伸带 + 编号标注**；
    哪条带压在斜面 / 锥面上，那条会变**红色**提醒"拉长它会破坏造型"。
  - **自动切分规则**（不设拉伸区时）：切分面必须落在够宽的空档里（≥ 全长的 20%），而且**跨过切分面的每一条边都必须平行于拖动轴**
    —— 跨切分面的面都是"顺着轴"的侧面，拉长它们等于把物体加长；斜角、凹槽、锥面不跨切分面，于是原样保留。
    位置优先取物体中部的 **48%~52%**；中部不平直时退到离中部最近的有效位置，实在没有就本次按整体缩放并在左上角写明原因。
- **收分（锥化）**：固定端截面不变、另一端绕轴线按比例收缩、中间截面线性过渡；逐顶点变形，**材质、贴图、柔化平滑、组结构全部保留**。
- **拖动吸附**（可关）：拾取鼠标附近几何的特征点 —— 组/组件的**包围盒 8 角点 + 6 面心 + 中心**，散几何的**端点 / 中点 / 圆心**；命中时显示品红标记与「拾取：角点/中心/…」。
- **锁定方向轴**：点一下手柄即锁定该轴，之后鼠标怎么动都只沿这条轴缩放，再点一下应用。
- **两点定位拉伸**：右键「拉伸到点…」→ 第一下点对象上"要移动的位置"，第二下点目标点，
  对象沿变形框轴拉伸，**起点精确落到目标点**（可吸到别的物体的角点 / 端点 / 圆心）；
  拖动过程中实时预览，`Esc` 取消。
- **精确输入**：右键「精确输入…」输入增量，正数延长、负数缩短；角点手柄可分别输入 X / Y / Z。
- **模式切换按钮**：视图左上角的半透明橙色圆角按钮，点一下就切换 拉伸缩放 / 收分（收分模式变形框变紫）。
- 操作全程在**一个撤销步骤**内，`Ctrl+Z` 一次整体回退。

1. 下载 `ban_taper_scale.rbz`（见 Releases，或按下方「从源码构建」自己生成）；

安装后出现：工具栏「变形框收分缩放」+ 菜单 `扩展程序 → 变形框收分缩放`。命令**始终可以点**。

## 使用

### 基本流程

1. **点工具栏按钮 / 菜单「变形框收分缩放」**（不需要先选中任何东西）；
2. 鼠标移到对象上会看到**青色虚线框**提示将要选中它；**点击**即选中并生成变形框；
3. `Shift` 或 `Ctrl`（Win）/ `Option`（Mac）点击可**加选**；
4. 拖手柄变形；**点空白处**可清空选择、重新挑对象；`Esc` 退出工具。

### 两种变形操作方式

1. **点一下 → 移动 → 再点一下（推荐）**：点手柄即**锁定方向轴**（绿色虚线标出），移动鼠标沿轴缩放，再点一下应用；`Esc` 取消。
2. **按住拖动**：按住手柄拖到目标位置松手，立即应用。

### 拖动吸附

拖动时会在鼠标附近寻找可吸附的特征点（屏幕 12 像素内），命中就画**品红方块**并在左上角显示类型：

| 鼠标附近的对象 | 可吸附的点 |
| --- | --- |
| 组 / 组件 | 包围盒 8 个角点、6 个面心、几何中心 |
| 散几何（面 / 线） | 端点、中点、圆弧圆心、面心 |

不需要时可在右键菜单里关掉：**「拖动时吸附到几何（端点/中点/圆心）」**。

### 拉伸区域设置（1~2 个区间）

面心拉伸默认「保持造型」，拉伸区由插件自动挑；你也可以自己指定：

1. 工具激活时**右键 → 「面心拉伸：拉伸区域设置…」**；
2. 两个输入框分别填区间（单位 %），第二个可以留空：

   | 填法 | 效果 |
   | --- | --- |
   | 两个都留空 | 回到自动（物体中部） |
   | `30-40` | 只让这一段拉伸，其余刚性平移 |
   | `30-40` + `60-70` | 两段各分一半伸长量，中间 40%~60% 不动 |

3. 写法很宽松：`30-40`、`30%~40%`、`30~40` 都认，顺序写反会自动纠正；相邻/重叠的区间自动合并；
   最多 2 个区间，填错会弹提示且不改动原设置。

百分比按**变形框轴线**算：`0%` = 变形框起点，`100%` = 另一端（画面上橙色带的位置就是实际位置）。
设置完画面上会画出橙色半透明拉伸带和编号（`拉伸区1 30%~40%`），左上角也会写一行当前拉伸区；
压在斜面/锥面上的拉伸带显示为**红色**。设了区间会自动切回「保持造型」模式，免得设完没反应。

### 两点定位拉伸（点原位置 → 点目标点）

不想算"要拉多少毫米"时用这个，直接把某个点送到目标位置：

1. 工具激活、变形框在的时候，右键 → **「拉伸到点…（先点原位置，再点目标点）」**；
2. **第一下**点对象上"要移动的位置"（自动吸附端点 / 角点 / 中点 / 圆心 / 其它物体的特征点）；
3. **第二下**点它要去的**目标点**（可以是别的物体上的点），立刻应用；拖动过程实时预览；
4. 也可以第一下按住不放拖到目标点松手；`Esc` 取消。

| 细节 | 说明 |
| --- | --- |
| 起点精确落位 | 保持造型 / 自定义拉伸区 / 整体缩放三种路径都会让起点**正好**落在目标点；起点在拉伸区里只走一半时，伸长量自动放大补上 |
| 拉伸轴 | 自动取两点差最大的那条变形框轴；也可以**用方向键锁定**：`→` 红轴 X、`←` 绿轴 Y、`↑`/`↓` 蓝轴 Z，再按同一个键解除（点第一下之前就能先按）；先指到某条轴的面心手柄再启动也可固定那条轴 |
| 极轴参考线 | 锁定轴后画面上画出极轴参考线，目标点按轴投影落点，所以第二下点得偏一点也没关系 |
| 固定端 | 离起点远的那一端；保持造型时切分面会自动让到起点之前，保证起点真的跟着走 |
| 适用模式 | 只在**拉伸缩放**模式下可用（收分模式菜单变灰）|

### 切换模式

- 点视图**左上角的橙色圆角按钮**（上面写「切换模式」）—— 不依赖任何键盘快捷键，Mac / Windows 通用；
- 或右键菜单：「拉伸缩放模式」/「收分模式」；
- 切换后左上角会弹出大字提示，收分模式的变形框整体变**紫色**，手柄数也随之变化（拉伸 14 个，收分 6 个）。

### 右键菜单一览

| 菜单项 | 作用 |
| --- | --- |
| 精确输入… | 输入增量（正数延长 / 负数缩短），角点可分别输入 X/Y/Z |
| 应用 / 取消当前锁定 | 结束或取消当前变形 |
| 拉伸缩放模式 / 收分模式 | 切换模式（同按钮）|
| 变形框对齐对象坐标 | 用对象自身轴向建框 / 改用世界坐标轴 |
| 面心拉伸：保持造型 / 整体缩放 | 面心拉伸的两种行为 |
| 面心拉伸：拉伸区域设置… | 填 1~2 个互不相连的拉伸区间（`30-40,60-70`）|
| 面心拉伸：拉伸区域＝自动 | 清掉自定义区间，回到自动取物体中部 |
| 拉伸到点… | 两点定位拉伸：先点原位置，再点目标点（只拉伸缩放模式可用）|
| 拖动时吸附到几何 | 吸附开关 |
| 收分时炸开圆/弧曲线 | 曲线处理开关 |

### 精确缩放

**方式一：右键「精确输入…」（推荐）** —— 先点一下手柄锁定方向轴，再右键：

| 输入 | 含义 |
| --- | --- |
| `100` | 沿锁定轴**延长 100**（按模型单位；模型是毫米就是 100mm）|
| `-100` | 沿锁定轴**缩短 100** |
| `100mm`、`3"` | 带单位时按该单位延长 / 缩短 |

**方式二：拖动时直接敲数字（VCB）**

| 输入 | 含义 |
| --- | --- |
| `100` / `-100` | 增量：延长 / 缩短 100（模型单位）|
| `100mm` | 带单位的增量 |
| `1.5x` / `*1.5` | 比例：放大到 1.5 倍 |
| `1200mm,800mm,1500mm` | 三个轴各自的增量（正负均可）|

**收分模式**的数值输入仍是「比例 / 端面尺寸」：`0.6` = 收分端缩到 0.6；`0.6,0.8` = 两个方向分别收缩；`600mm,900mm` = 收分端截面精确为 600×900mm。

### 「收分」的数学

```
t = 沿收分轴的归一化位置（固定端 = 0，收分端 = 1）
截面缩放 s(t) = 1 + (factor - 1) · t
结果点 = 轴线上的对应点 + s(t) · (原点到轴线的垂距)
```

## 注意事项

1. **收分会把组件「独立化」**：如果选中的组件被多处引用，插件会自动 `make_unique`，只影响你选中的那个实例。
2. **收分默认会炸开圆/弧曲线**（避免顶点移动后 SketchUp 重新拟合曲线导致形状异常），可在右键菜单关闭。
3. 收分是逐顶点变形：顶点特别多（约 8 万以上）时实时预览可能略卡，状态栏会提示。
4. 收分不改变变形框本身，可反复微调；拉伸缩放会同步更新变形框。
5. 「保持造型」默认自动挑一条**平直**的切分面（不切斜面/锥面/凹槽），位置优先取物体中部的 48%~52%；
   想自己决定拉伸位置就用右键「拉伸区域设置…」。整根都是锥面/曲面、找不到平直位置时，本次会按整体缩放处理，
   左上角会写明原因，画面上也不会出现橙色拉伸带。
6. **不占用任何键盘快捷键**（早期版本的 Tab / M 已移除）。
7. 需要 SketchUp 2019 或更高版本（用到 `make_unique`、`transform_by_vectors` 等 API）。
8. 用鼠标中键旋转 / 平移视图后，指针会自动变回箭头（插件在 `onSetCursor` / `resume` 里显式接管了指针，
   不会影响 SketchUp 自带的中键旋转）。
